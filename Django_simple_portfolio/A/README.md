# Django Bilingual Personal Blog

A simple personal blog/portfolio website built with Django. It includes an **About Me** section, **Skills**, and **Contact** information. The site fully supports **English and Persian (Farsi)** languages with a button to switch between them.

## Features

- 🌐 **Bilingual**: English / Persian with a language toggle button.
- 👤 **About Me** page with a short bio.
- 🛠️ **Skills** section (programming languages, frameworks, tools).
- 📬 **Contact** section (email, GitHub, etc.).
- 🧩 Clean and simple Django structure – easy to extend into a full blog.

## Technologies Used

- Python 3.x
- Django (latest stable)
- HTML/CSS (Bootstrap or custom)
